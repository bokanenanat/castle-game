# 🏰 Castle Game | بازی قلعه

یه بازی استراتژیک تحت وب که با **HTML, CSS, JavaScript** خالص ساخته شده.

---

## 🎮 درباره بازی
توی این بازی، تو فرمانروای یه قلعه‌ای و باید:
- منابع جمع کنی (طلا، چوب، گندم)
- سرباز بسازی (سواره‌نظام، پیاده‌نظام، کماندار، ارابه)
- قلعه بسازی و ارتقا بدی
- به قلعه‌های دشمن حمله کنی
- با هیولاها بجنگی

---

## ⚔️ امکانات بازی
- ✅ سیستم منابع (طلا، چوب، گندم)
- ✅ ۴ نوع نیرو (سواره‌نظام، پیاده‌نظام، کماندار، ارابه)
- ✅ ساخت و ارتقاء ساختمان‌ها
- ✅ حمله به قلعه دشمن
- ✅ حمله به هیولا
- ✅ نقشه تعاملی (WarMap)
- ✅ فروشگاه (Shop)
- ✅ سیستم پروفایل و انتخاب فرمانروا
- ✅ موسیقی و افکت‌های صوتی
- ✅ ذخیره‌سازی خودکار با LocalStorage

---

## 🛠️ تکنولوژی‌ها
- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage (برای ذخیره اطلاعات)
